# MDX Content Templates

Copy the template and fill in the empty props.

| Template | URL Path |
|----------|----------|
| `homepage-template.mdx` | Homepage sections |
| `feature-grid-template.mdx` | Homepage features grid |
| `blog-template.mdx` | `/blogs/{slug}` |
| `case-study-template.mdx` | `/case-studies/{slug}` |
| `feature-template.mdx` | `/features/{slug}` |
| `use-case-template.mdx` | `/use-cases/{industry}/{slug}` |
