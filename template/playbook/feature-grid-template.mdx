---

## **1. The Grid Item Strategy**
> **The Job**: Translate a boring feature into a business lifesaver.

### **🧠 Copy Strategy: FAB (Feature-Advantage-Benefit)**
*   **Definition**:
    *   **Feature**: What the thing is physically.
    *   **Advantage**: What it does better than the alternative.
    *   **Benefit**: The emotional or financial payoff for the user.
*   **Example for "Managed Hosting"**:
    *   *Feature*: "We host workflows on private servers."
    *   *Advantage*: "No need for you to manage AWS or DigitalOcean droplets."
    *   *Benefit*: "Eliminate IT headaches and save $500/mo on DevOps."

### **What to Write (The Template per Card)**
1.  **Headline**: The Feature (e.g., "Self-Healing Workflows")
2.  **Body**: The Benefit (e.g., "Our system detects errors and retries automatically, so you never lose data.")
3.  **Link**: "Learn more ->"

### **🎨 Visual Director Notes (The Icons)**
*   **Requirement**: DO NOT use generic "FontAwesome" icons. Use **Custom Illustrated Icons**.
*   **Specific Instructions**:
    *   **For "Design"**: Show a blueprint being drawn by a ghost hand.
    *   **For "Monitoring"**: Show a radar sweep animation or a pulse line.
    *   **For "Pricing"**: Show a coin dropping into a piggy bank (2rs concept).
*   **Video Concept**: If this is a high-budget page, make each card a **Video Tile** that plays a 2-second loop of the feature in action (e.g., code scrolling, green lights pulsing) on hover.

## **2. Content checklist for "The Service"**
*   **Item 1: Requirement Analysis**
    *   *Visual*: A chat bubbles icon (We talk).
    *   *Copy*: "We listen to your needs and map the logic."
*   **Item 2: Custom Development**
    *   *Visual*: A code bracket icon `{ }` with a gear.
    *   *Copy*: "Our engineers write robust code for your unique edge cases."
*   **Item 3: Secure Hosting**
    *   *Visual*: A Shield or Server Rack.
    *   *Copy*: "Bank-grade encryption and 99.9% uptime."

### **✅ Dos & ❌ Don'ts**
*   ✅ **DO** focus on "We do it for you."
*   ❌ **DON'T** focus on "You can configure it." (User doesn't want to configure).
