---

## **1. Hero Section**
### **🧠 Copy Strategy: The "So What?" Test**
*   **Concept**: Don't sell the feature. Sell the *result* of the feature.
*   **Rule**: Keep asking "So what?" until you hit an emotion.
    *   *Feature*: "We have logs." -> *So what?* -> "We can see errors." -> *So what?* -> "We fix them fast." -> *So what?* -> **"You never lose a customer to a glitch." (Bingo).**

### **🎨 Visual Director Notes**
*   **Visual**: **Isometric 3D Illustration**.
*   **Description**: An object representing the feature (e.g., A Robot Arm for "Automation", A Vault for "Security") floating in the center, casting a soft shadow.
