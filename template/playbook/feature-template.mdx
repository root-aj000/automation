# 🏗️ Feature Deep-Dive Copy Playbook [FULLY MANAGED MODEL]

> **Business Context**: When we talk about a "feature" like "AI Chatbots", we are selling the **result** of that feature, because WE implement it.

---

## 1. Hero (The Promise)
> **Buyer Question**: *"What problem are you solving?"* (Ref 03)
> **Business Answer**: Automating a specific task end-to-end. (Ref 01)

*   **What to Write**: "Robust AI Data Extraction, Built & Managed For You."

---

## 2. How It Works (The "Black Box")
> **Buyer Question**: *"Is this hard to set up?"* (Ref 03)
> **Business Answer**: You provide inputs; we provide outputs. (Ref 01)

*   **Framework**: **Input-Process-Output**
*   **What to Write**:
    1.  **Input**: "Forward your emails to us."
    2.  **Process**: "Our AI extracts the data (managed on our servers)."
    3.  **Output**: "We insert clean data into your CRM."

---

## 3. The "No-Headache" Guarantee
> **Buyer Question**: *"What if it breaks?"* (Ref 03)
> **Business Answer**: Maintenance included. (Ref 01)

*   **What to Write**:
    *   "Forget about API updates or breaking changes."
    *   "Our team monitors this feature 24/7."

---

## 4. FAQ (Feature Specific)
> **Buyer Question**: *"Can I customize this?"* (Ref 03)
> **Business Answer**: Yes, we code the logic. (Ref 01)

*   **Required Q&A**:
    1.  **Q**: "Can I change the logic later?"
        *   **A**: "Just message us. We update your workflow instantly."
    2.  **Q**: "Do I need an OpenAI account?"
        *   **A**: "No, we handle all API keys and billing."

---

## 🔴 Copywriter Checklist
*   [ ] Did I assure the user they don't have to configure the AI?
*   [ ] Did I emphasize the "Ongoing Support" aspect?
